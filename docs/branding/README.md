# Фирменные значки Clod Clash

Набор для тех, кто оформляет свои страницы — сайт, инструкцию, страницу
загрузки — под клиент. Здесь лежит та же иконка, что стоит у приложения,
в форматах и цветовых схемах, готовых к вёрстке. Геометрия знака во всех
файлах одинаковая; меняется только плитка и заливка.

## Файлы

| Файл | Что это | Куда класть |
| --- | --- | --- |
| `icon.svg` | Каноническая иконка приложения: фирменный градиент, белый робот | Куда угодно — у неё собственный фон |
| `icon-dark.svg` | Плитка в тёмной схеме приложения (`#0E1116`) | Тёмные страницы, когда градиентная плитка слишком яркая |
| `icon-light.svg` | Плитка в светлой схеме приложения (`#F1F4F9`), робот в градиенте | Светлые страницы |
| `mark-white.svg` | Только робот, белый, прозрачный фон | Поверх тёмного фона или фотографии |
| `mark-slate.svg` | Только робот, графит `#1A2130`, прозрачный фон | Поверх светлого фона |
| `mark-brand.svg` | Только робот в фирменном градиенте, прозрачный фон | Светлые страницы, где нужен цветной знак без плитки |

У марок глаза и рот прорезаны насквозь: сквозь них виден фон страницы,
поэтому знак остаётся аккуратным на любом цвете подложки.

## Цвета

Фирменный градиент знака: `#6366F1 → #5B48EE → #7C3AED` (диагональ, из
левого верхнего угла).

Схемы приложения, если страница хочет совпадать с ним по тону:

| | Светлая | Тёмная |
| --- | --- | --- |
| Фон | `#F1F4F9` | `#0E1116` |
| Панели | `#FFFFFF` | `#191C21` |
| Текст | `#1A2130` | `#EBEEF5` |
| Вторичный текст | `#5A6478` | `#9AA3B5` |
| Акцент | `#2E7CF6` | `#4287F5` |

## Правила

Иконку не перекрашивать в свои цвета, не наклонять, не добавлять тени,
обводки и блики — берите готовый вариант под свой фон из таблицы выше.
Скругление плитки уже в файле, класть её в дополнительную рамку не нужно.
Минимальный размер плитки на странице — 32 пикселя, марок — 24 пикселя
по высоте; ниже этого глаза сливаются. Вокруг знака оставляйте свободное
поле не меньше четверти его ширины.

Название пишется двумя словами: Clod Clash.
