Settings open with the ⚙ gear in the home screen header (in advanced mode — with the **Settings**
tile).

## System Setting

<Shot src="ru/settings.png" alt="Settings: system, provider block, sections" width={720} />

| Item | What it does |
| --- | --- |
| **TUN Mode** | captures the traffic of all programs. The gear — stack and routing; the wrench icon — install or repair the background service |
| **System Proxy** | proxy for browsers and most programs. The gear — address, PAC mode, Proxy Guard, bypass list |
| **Connect on launch** | turn on the connection right after the app starts |
| **Start with the system** | launch the app when you sign in to the system |
| **Start in the tray** | don't show the window on launch |
| **Override system DNS** | macOS only |

The checked TUN and system proxy switches are exactly what the connect button turns on.
Details are in [Connection](/en/docs/user/connection).

## Provider block

Named after the subscription: the links the provider sent — account, support, bot, status,
guide. Only the ones that were sent are shown.

## General

<Shot src="ru/settings-basic.png" alt="The General section" width={720} />

- **Language** and **Theme Mode** (Light, Dark, System).
- **Advanced mode** — the two-column home view, see [Home screen](/en/docs/user/home).
- **Fit window to content**.
- **Device identification** — the identifier for the device limit; the tooltip shows exactly what
  is sent to the provider.
- **Support report** — the copy icon puts the report on the clipboard, see
  [Support report](/en/docs/user/support).
- **Clod Version** — the gear checks for updates.
- **Pre-release builds** — receive alpha and beta versions, see [Updates](/en/docs/user/updates).

## Advanced settings

<Shot src="ru/settings-advanced.png" alt="The Advanced settings section" width={720} />

### Appearance and behaviour

- **Subscription notifications** — reminders about the end of the term and traffic.
- **Tray Click Event** — what clicking the tray icon does (not on Linux).
- **Theme Setting** — colors, font, the provider's styling.
- **Layout Setting** — group icons, notification position, tray icons, speed in the tray (macOS
  only).
- **Miscellaneous** — app log, closing connections when switching servers, automatic update
  checks, latency test address and timeout.
- **Hotkey Setting**, **Terminal proxy command**, **Startup Script**.

### Clash Setting

- **Routing mode** — Rule, Global, Direct.
- **LAN sharing** — share the proxy with other devices (for example, WSL,
  Docker, a phone on the same network).
- **IPv6** — shows whether IPv6 is enabled in the subscription.
- **DNS Overwrite** — your own DNS on top of the subscription; only what you changed is stored.
- **Unified Delay** and **Log Level** — "As in the subscription" or your choice.
- **Port Config** — the proxy port (by default from the subscription, otherwise 7897).
- **External Controller**, **Web UI**.
- **Clash Core** — choose the core (Clod Core or Mihomo), update and restart it, see
  [Updates](/en/docs/user/updates#core).
- **Open UWP tool** (Windows only), **Update GeoData**, **Tunnel Management**.

<Shot src="ru/core-dialog.png" alt="The “Clash Core” window" width={720} />

### Tools

**Proxies**, **Rules**, **Connections**, **Logs** — technical screens. The **On home** switch
puts a shortcut to the screen on the advanced-mode home screen. More about "Proxies" and "Connections" in
[Servers](/en/docs/user/servers).

### Maintenance

- **Backup Setting** — backups of settings and subscriptions on this computer: on a schedule or
  with a button, saved to a file and restored from one.
- **Runtime Config** and **As the provider sent it** — view the final core config and
  the provider's original response.
- **Open Conf Dir**, **Open Core Dir**, **Open Logs Dir**.
- **Export logs as an archive** — for support, see [Support report](/en/docs/user/support).
- **Lightweight mode settings**, **Dev Tools**, **Exit**.
