## Приложение

Приложение проверяет обновления само — при запуске и раз в сутки — и, найдя новую версию,
показывает окно со списком изменений. **Обновить** скачивает и ставит её; скачивание идёт в фоне.

<Shot src="ru/update.png" alt="Окно «Новая версия»" />

- **Перейти на страницу релизов** — открыть релиз на GitHub.
- **Отмена** — закрыть окно; эту версию приложение больше не предложит до следующего запуска.

Проверить вручную: **Настройки → Основные**, шестерёнка в строке **Версия Clod**. Если прямой путь
до GitHub закрыт, проверка повторяется через собственный прокси.

Автоматическую проверку можно выключить: **Продвинутые настройки → Оформление и поведение → Прочее →
Автоматическая проверка обновлений**.

<Callout title="Портативная сборка Windows">
Портативная сборка сама не обновляется: в фоне обновления не скачивает, а окно
обновления вместо кнопки «Обновить» предлагает страницу релизов. Новую версию берите со
[страницы загрузки](/ru/download).
</Callout>

## Предварительные сборки

**Настройки → Основные → Предварительные сборки** (по умолчанию выключено). С переключателем
приходят альфа- и бета-версии — в них раньше появляются новые функции и исправления, но проверены
они меньше. Без него — только стабильные релизы. Постоянные ссылки на
[странице загрузки](/ru/download) всегда ведут на последнюю обычную версию.

## Ядро

В каждой сборке два ядра, они переключаются в **Настройки → Продвинутые настройки → Настройки Clash
→ Ядро Clash**:

- **Clod Core** (по умолчанию) — наш форк стабильного Mihomo с исправленными проверками узлов и
  новой библиотекой TLS-отпечатков. Подробно — в [«Ядре Clod Core»](/ru/docs/provider/core).
- **Mihomo** — запасное ядро: последний стабильный релиз MetaCubeX без изменений. Само не включается,
  только выбором в этом окне.

<Shot src="ru/core-dialog.png" alt="Окно «Ядро Clash»" width={720} />

Ядро обновляется вместе с приложением. Обновить его отдельно — кнопка **Обновить** в том же окне;
каждое ядро обновляется из своих релизов (Clod Core — с clod-core, Mihomo — с MetaCubeX).

- Если папка программы доступна на запись (обычно это macOS), ядро обновляет само приложение:
  скачивает, сверяет контрольную сумму, подменяет файл, а если новое ядро не запустилось —
  возвращает прежнее. Остановленное ядро так не обновляется.
- Иначе ядро обновляет себя само через фоновую службу. Без службы (на Windows, на Linux из пакета)
  кнопка покажет подсказку: ядро обновится вместе с приложением. Стоковый Mihomo на Windows после
  обновления оставляет лишнюю копию себя, которая держит порт до перезагрузки компьютера, — кнопка
  предупредит об этом заранее.

## Подписка

Подписка (список серверов, трафик, срок) обновляется отдельно от приложения — сама по интервалу или
вручную. Подробно — в [«Добавлении подписки»](/ru/docs/user/subscription#обновление-подписки).
