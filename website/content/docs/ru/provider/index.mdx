Раздел для тех, кто держит VPN-сервис на панели Remnawave. Пользователю здесь делать ничего не
нужно — для него раздел [«Пользователю»](/ru/docs/user).

## Что сделать

<Steps>
<Step>

**Добавить правило ответа для клиента**, чтобы панель отдавала Clod Clash конфигурацию Mihomo, и
проверить шаблон — [«Настройка панели»](/ru/docs/provider/panel).

</Step>
<Step>

**Отдать заголовки подписки**: название, трафик и срок, интервал обновления, ссылку на поддержку —
[«Заголовки подписки»](/ru/docs/provider/headers).

</Step>
<Step>

**По желанию — собственные заголовки `clod-*`**: кабинет, объявления, запасной адрес, замок режима,
способ подключения, вид окна, проверка серверов 16–20 — [«Заголовки clod-*»](/ru/docs/provider/clod-headers).

</Step>
<Step>

**По желанию — защищённый канал** через прослойку
[remnawave-subscription-middleware](https://github.com/Mrvibecodic/remnawave-subscription-middleware) —
[«Настройка панели»](/ru/docs/provider/panel#4-защищённый-канал-и-отчёты).

</Step>
</Steps>

## Где пользователь видит данные панели

<Shot src="ru/home-connected.png" alt="Главный экран: название, объявление, трафик и срок, ссылки провайдера" />

| Что видно | Откуда берётся |
| --- | --- |
| Название подписки в шапке и на карточке | `profile-title`; своё название пользователя показывается первым |
| Карточки «Трафик» и «Срок», метки «Истекает», «Истекла», «Трафик кончился» | `subscription-userinfo` |
| Объявление под шапкой | `announce` / `clod-announce`, ссылка — `announce-url` |
| Промо-баннер, который можно закрыть | `clod-promo`, `clod-promo-url` |
| Кнопки «Кабинет», «Поддержка», «Бот», «Мониторинг», «Инструкция» | `clod-portal-url`, `support-url`, `clod-bot-url`, `clod-monitor-url`, `clod-guide-url` |
| «Страница подписки» в меню карточки | `profile-web-page-url` |
| Интервал обновления в свойствах подписки (заблокирован) | `profile-update-interval` |
| Напоминания о сроке и трафике | `notify-expire-days`, `notify-traffic-percent` |
| Режим «задан провайдером» | `clod-lock-mode` |
| Что включает кнопка подключения | `clod-connect-mode` |
| Простой или расширенный вид по умолчанию | `clod-simple-mode` |
| Цвета пинга, полоски, точка или цифры | `clod-ping`, `clod-disable-ping`, `clod-latency-style` |
| Подпись протокола у серверов | скрывается `clod-hide-badges`; своё описание — `serverDescription` узла |
| Значок-снежинка у сервера | `clod-16-20-check` |
| Окно «Лимит устройств исчерпан» | `x-hwid-max-devices-reached`, `x-hwid-limit`, `x-hwid-not-supported` |
| «Серверов нет» с причиной | узлы-заглушки панели; показать как есть — `clod-show-0hosts` |

## Что важно знать

- Клиент принимает подписки только по `https://` (и диплинки `clash://` / `clodclash://` с адресом
  `https://` внутри).
- Ошибки, которые пользователь видит при сбое подписки, перечислены в
  [«Типовых ошибках»](/ru/docs/user/errors) — пригодится поддержке.
- Какое ядро внутри и что клиент задаёт ему сам — [«Ядро Clod Core»](/ru/docs/provider/core).
