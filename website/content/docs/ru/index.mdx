Clod Clash — приложение для Windows, macOS и Linux, которое подключает компьютер к VPN-сервису по
ссылке на подписку. Вставляете ссылку, нажимаете одну кнопку — и трафик идёт через серверы вашего
провайдера.

Документация разделена на две части — выберите свою.
