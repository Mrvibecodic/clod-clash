Полный справочник с правилами разбора, синонимами и примерами — в репозитории:
**[docs/HEADERS.md](https://github.com/Mrvibecodic/clod-clash/blob/main/docs/HEADERS.md)**.
Собственные заголовки клиента с поддержкой по платформам — на странице
[Заголовки clod-*](/docs/providers/clod-headers).

## Что отправляет клиент

| Заголовок | Значение |
| --- | --- |
| `User-Agent` | `ClodClash/<версия>`, например `ClodClash/0.1.11-alpha.3`; если в свойствах подписки заполнено поле «User Agent», уходит оно, и правило `^ClodClash` в панели на такой запрос может не сработать |
| `Accept` | `*/*` |
| `x-hwid` | идентификатор устройства — пока включена «Идентификация устройства» (по умолчанию включена) |
| `x-device-os`, `x-ver-os`, `x-device-model` | система, её версия и модель — вместе с `x-hwid`; имя компьютера не отправляется |

С включённым «Защищённым соединением» (свойства подписки) эти значения уходят не
заголовками, а внутри зашифрованного запроса к прослойке.

## Что понимает в ответе

| Заголовок | Что делает |
| --- | --- |
| `profile-title` | название подписки, обновляется с каждым ответом; своё название пользователя показывается первым: «Своё (от панели)» |
| `content-disposition` | запасное название, если нет `profile-title` |
| `subscription-userinfo` | трафик и срок на карточке |
| `subscription-refill-date` | дата пополнения трафика |
| `profile-update-interval` | интервал автообновления в часах; применяется при каждом обновлении, пока пользователь не задал свой. Если он ни разу не приходил и своего нет — по расписанию не обновляется; пропавший заголовок оставляет последний интервал, остановить — `0` |
| `profile-logo` | логотип провайдера (только `https`), хранится локально |
| `profile-web-page-url` | пункт «Главная» в меню карточки подписки |
| `support-url` | кнопка «Поддержка» (`https`, `tg:`, `mailto:`) |
| `announce`, `announce-url` | постоянное объявление и ссылка из него |
| `new-url`, `new-domain` | переезд подписки на новый адрес — после удачной пробной загрузки |
| `fallback-url`, `fallback-domain` | запасные адреса той же панели — если основной адрес не дал годную подписку |
| `x-hwid-not-supported`, `x-hwid-max-devices-reached`, `x-hwid-limit` | отказ по устройству: окно с названием подписки, прежние серверы убираются |
| `notify-expire-days`, `notify-traffic-percent` | пороги напоминаний о сроке и трафике (`off` выключает) |
| `Date` | срок считается по часам панели, неверное время на компьютере его не сдвигает |
| `clod-*` | собственные заголовки клиента — см. [Заголовки clod-*](/docs/providers/clod-headers) |

Дополнительные заголовки задаются в панели через `customResponseHeaders`.
Значения с не-ASCII текстом надёжнее отдавать как `base64:<payload>`;
ссылки — только `https://`; `support-url` и `clod-bot-url` принимают ещё `tg:` и `mailto:`.
